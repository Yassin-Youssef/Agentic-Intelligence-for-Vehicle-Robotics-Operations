# Fleet Operational Report

This document describes the structure and purpose of the fleet operational
report generated by the agentic vehicle and robotics monitoring system.

The report is produced automatically after deterministic analysis of telemetry
data and serves as a human-readable summary for engineers and operators.

---

## Purpose

The fleet operational report is designed to:

- Summarize vehicle health status
- Present key performance indicators (KPIs)
- Highlight detected anomalies
- Support maintenance and operational decision-making

All metrics and classifications in the report are derived from deterministic,
rule-based analysis.

---

## Report Structure

The report is organized into **per-vehicle sections**.

Each vehicle section contains:

- Vehicle identifier
- Overall health status
- Per-metric KPI summary:
  - Mean
  - Minimum
  - Maximum
  - Standard deviation
- Anomaly information per metric

## Health Status Interpretation

Vehicle health status is assigned deterministically using rule-based thresholds:

- **Healthy** – minimal or no anomalies
- **Warning** – moderate anomalies affecting multiple metrics
- **Critical** – high anomaly count or widespread metric degradation

The report reflects the classification output directly and does not modify it.

---

## Notes

- The report is generated in plain text for transparency and portability.
- The structure is intentionally simple to allow future parsing or conversion
  to other formats such as JSON or dashboards.
- AI-generated explanations are handled separately and are not embedded in this
  deterministic report.
